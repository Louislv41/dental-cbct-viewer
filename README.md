# CT / CBCT 阅片器

给 Mac 用的轻量 DICOM 阅片工具。双击即可打开，浏览器里随意看轴位 / 冠状位 / 矢状位和三维重建。

---

## 一、怎么启动

**方法 A（最简单）**：双击 `启动阅片器.command`

- 会自动找到上一级目录里的 `.dcm` 文件
- 自动打开浏览器（默认地址 http://127.0.0.1:8788）
- 关闭弹出的终端窗口即退出

> 第一次双击如果提示「无法打开，因为无法验证开发者」：
> 右键 → 打开 → 打开。或者在「系统设置 → 隐私与安全性」里点「仍要打开」。

**方法 B（终端）**：

```bash
cd "CT阅片器"
python3 app.py                      # 自动找同目录/上一级目录的 dicom
python3 app.py /path/to/dicom 8788  # 指定目录和端口
```

**换一套 CT 看**：把新的 DICOM 文件夹放到本项目**上一级目录**（和 `CT阅片器` 同级），再双击启动即可；或在终端里指定路径：

```bash
python3 app.py /path/to/dicom 8788
```

## 二、界面操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 调窗宽窗位（对比度 / 亮度） |
| 单击 | 把十字线定位到该点，四个视图联动 |
| 滚轮 | 换层（逐层翻） |
| ⌘ / Ctrl + 滚轮 | 缩放 |
| Shift + 拖动 | 平移 |
| 方向键 | 换层（Shift 加速 10 层） |
| 双击 | 复位缩放 / 3D 视角 |
| 3D 区拖动 | 旋转三维模型 |
| 3D 区滚轮 | 缩放三维模型 |

**方位标记（R / L）**

- 工具栏的 `左右标记` 按钮可开关（默认开）。
- 轴位 / 冠状位：画面左边标 **R**、右边标 **L** —— 这是看片的标准姿势（就像面对患者），
  **屏幕左边是患者自己的右边**。上下分别标 前 A / 后 P 或 上 S / 下 I。
- 矢状位：左 **前 A**、右 **后 P**。
- 三维：正前方看是左 R 右 L，转到背面会自动对调。
- 导出的 PNG 会连标记一起导出。
- **判定依据是 DICOM 文件自带的 Image Orientation (Patient) 方向信息，不是猜的**：
  程序读取 `(0020,0037)` 这个字段，按 LPS 人体坐标系（+x=患者左、+y=后、+z=上）算出
  屏幕四条边分别对应患者的哪个方向，再决定标 R 还是 L。换一台机器、方向字段不同的数据，
  标记会自动跟着变，不需要改代码。

**工具栏**

- 窗宽窗位预设：骨/牙、细节、软组织、全范围
- `导出当前视图 PNG`：把当前选中的窗格存成图片（默认轴位，点一下哪个窗格就导出哪个）
- 3D 预设：骨+牙 / 只看牙齿 / 半透明
- `自动旋转`：三维模型自动转圈

## 三、命令行脚本（批量出图）

`ctlab.py` 适合批量导出，或者写进自己的流程。

```bash
# 检查信息
python3 ctlab.py info

# 单张切面：z=轴位, y=冠状位, x=矢状位
python3 ctlab.py slice --axis z --at 200 -o slice200.png
python3 ctlab.py slice --axis x --at 277 -o sag277.png --w 1800 --l 700

# 批量导出（100~300 层，每 10 层一张）
python3 ctlab.py slice --axis z --range 100:300:10 -o out/

# 三个方向的完整序列
python3 ctlab.py mpr --step 5 -o mpr/

# 拼接多格大图
python3 ctlab.py montage --axis z --step 20 --cols 6 -o overview.jpg

# 全景片
python3 ctlab.py pano -o 全景片.jpg

# 三维图（az 左右转，el 上下俯仰，th 阈值）
python3 ctlab.py render3d --az 35 --el 10 -o 3d.png
python3 ctlab.py render3d --az 0 --th 900 -o 只有牙齿.png

# 3D 旋转视频（需要 ffmpeg）
python3 ctlab.py spin --frames 60 -o 旋转.mp4
```

常用参数：`--w` 窗宽、`--l` 窗位、`--th` 3D 阈值、`--down` 3D 降采样倍数（越大越快、越糊）。

## 四、示例数据是什么

| 项目 | 值 |

## 五、文件说明

```
CT阅片器/
├── 启动阅片器.command   双击启动
├── app.py               后台服务（切片 / MPR / 3D 渲染）
├── dicom_io.py          DICOM 解析（自己写的，只依赖 numpy）
├── render_lib.py        窗宽窗位、体渲染等算法
├── ctlab.py             命令行批量出图
├── pano.py / pano2.py   全景片重建（沿牙弓曲线展平）
├── static/index.html    前端界面
└── 导出图/               已经生成好的图，可以直接看
```

## 六、依赖

Python 3 + numpy + scipy + Pillow。生成视频另外需要 ffmpeg。
`启动阅片器.command` 会自动检测，缺了会帮你装。

## 七、说明

- 本工具没有任何联网行为，所有处理都在本机完成，数据不出本机。
- 渲染结果是给「看清楚结构」用的，**不能替代放射科 / 口腔科医生的诊断**。
